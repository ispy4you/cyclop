# Локальная сборка вместо CI

CI в `akalikbergenov/cyclop` не запускается на PR от новых контрибьюторов без
ручного апрува (issue #54). Пока апрувить некому, эти два скрипта дают тот же
ответ на своей машине.

    bin/local-ci.sh      — точная реплика .github/workflows/build.yml
    bin/rebuild-next.sh  — пересобрать ветку next из свежего main и открытых PR

Рядом со скриптами должен лежать клон репозитория в каталоге `cyclop`.
